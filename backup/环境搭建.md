# 安装miniconda
miniconda版本列表链接
[https://repo.anaconda.com/miniconda](url)

前面以及安装好Ubuntu，现在打开Ubuntu终端
下载
```Ubuntu
wget [对应版本网络链接]
# 例如：wget https://repo.anaconda.com/miniconda/Miniconda3-py310_26.3.2-2-Linux-x86_64.sh
```
安装
```Ubuntu
bash [安装包名称]
# 例如：bash Miniconda3-py310_26.3.2-2-Linux-x86_64.sh
```
# 修改源
老版本正常备份并替换
24.04特殊，其路径变为/etc/apt/sources.list.d/ubuntu.sources，具体可参考
[https://www.cnblogs.com/Thenext/p/18430885](url)
备份源文件
```Ubuntu
sudo cp /etc/apt/sources.list.d/ubuntu.sources /etc/apt/sources.list.d/ubuntu.sources.bak
```

编辑源文件
```Ubuntu
sudo vim /etc/apt/sources.list.d/ubuntu.sources
```

退回到终端窗口后
更新源
```Ubuntu
sudo apt-get update
```
更新软件
```Ubuntu
sudo apt-get upgrade -y
```

# 创建虚拟环境
创建任意环境
```conda
conda create -n [名称]
```
-n和--name是一样的
创建基于python2.7.18的语言环境
```conda
conda create --name python27 python=2.7.18
```
检查当前python版本
```conda
python --version
```

如果要移除环境，需要先退回到base环境
```conda
conda activate base
```
先查看环境列表
```conda
conda env list
```

移除环境
```conda
conda remove -n [环境名称] --all
```

进入或退出环境
```conda
conda activate [环境名称]
```
```conda
conda deactivate [环境名称]
```

进入已创建的环境并安装包
```conda
conda install [包的名称]
```
或
```conda
conda install --force [包的名称]
```

# jupyter安装
先在base创建单独的环境
```conda
conda create -n python
```

然后进入jupyter环境，在里面安装jupyter
```conda
conda install jupyter notebook
```
现在在jupyter中嵌入python2.7的内核，由于python2.7版本较老，与jupyter兼容性较差，这里需要特殊处理
以下操作都在python2.7环境中进行，先进入python2.7环境
清理可能存在的不兼容残留包
```conda
pip uninstall -y ipykernel ipython traitlets decorator jupyter_client pyzmq
```
一次性安装全套兼容 Python 2.7 的指定版本内核包
```conda
pip install \
  ipython==5.10.0 \
  ipykernel==4.10.1 \
  traitlets==4.3.3 \
  decorator==4.4.2 \
  jupyter_client==5.3.4 \
  pyzmq==19.0.2
```
验证内核模块是否正常
```conda
python -c "import ipykernel; print('内核模块安装成功')"
```
将 Python 2.7 内核注册到 Jupyter
```conda
python -m ipykernel install --user --name python27 --display-name "Python 2.7"
```
注册成功后会提示 `Installed kernelspec python27 in /home/你的用户名/.local/share/jupyter/kernels/python27`
